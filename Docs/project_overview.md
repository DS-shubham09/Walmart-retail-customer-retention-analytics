# Project Overview: Walmart Retail Customer Retention Analytics

## 1. Project Summary
This project uses SQL Server and Power BI to explore retail customer churn, customer lifetime value (CLV), loyalty-program engagement, and revenue patterns. The aim is to turn customer and transaction data into clear business insights that can help identify areas for further investigation.

## 2. Business Problem
Retail businesses need to understand which customer groups show higher churn, which product categories contribute the most revenue, how customers differ in estimated value, and how loyalty-program points are being earned and redeemed.

## 3. Project Objectives
- Calculate and review the overall customer churn rate.
- Compare churn rates across regions and age groups.
- Analyze revenue contribution by product category.
- Review the distribution of customers across CLV segments.
- Compare loyalty points earned and redeemed by loyalty tier.
- Present results in Power BI dashboards and a business insights report.

## 4. Tools and Technologies
- **SQL Server:** data exploration, aggregation, and business analysis queries.
- **Power BI:** interactive dashboards and visual comparisons.
- **DAX:** calculated columns and measures used in the Power BI report.
- **GitHub:** project documentation and portfolio sharing.

## 5. Dataset Tables
- `Customer_Demographics` — age, gender, region, income level, membership date, and preferred channel.
- `Customer_Transactions` — transaction dates, amounts, product categories, stores, and promotion information.
- `Store_Locations` — store type, region, and opening year.
- `Loyalty_Program` — loyalty tier and points earned or redeemed.
- `Churn_Labelled_Customers` — last purchase date, churn flag, and churn reason.

Document the actual dataset source and license before publicly sharing any underlying data.

## 6. Project Workflow
1. Review the tables and check data quality.
2. Use SQL to summarize customer, churn, revenue, CLV, loyalty, store, and promotion data.
3. Build Power BI visuals and interactive filters.
4. Record verified results and interpretations in the Business Insights report.
5. Document the project and publish only permitted files to GitHub.

## 7. Deliverables
- Power BI report (`.pbix`).
- SQL analysis queries (`.sql`).
- Business insights report (`.pdf`).
- Dashboard screenshots (`.png`).
- Project documentation (`.md`).

## 8. Scope and Caution
This is a descriptive analytics project. The patterns shown are not proof that one factor causes churn or revenue changes. Findings and recommendations should be validated with further analysis or business testing.
