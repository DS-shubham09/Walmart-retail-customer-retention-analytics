# Walmart Retail Customer Retention Analytics

## Project Overview
A retail customer analytics project using SQL Server and Power BI to analyze customer churn, customer lifetime value (CLV), loyalty-program engagement, and revenue patterns.

## Objectives
- Analyze overall customer churn and compare churn by region and age group.
- Examine revenue contribution by product category.
- Review customers across CLV segments.
- Compare loyalty points earned and redeemed across loyalty tiers.
- Present findings in dashboards and a business insights report.

## Tools
- SQL Server
- Power BI and DAX
- GitHub

## Repository Structure
- `data/` — dataset or a README describing the data source and fields, if sharing the data is permitted.
- `PowerBI/` — Power BI report file.
- `SQL/` — SQL analysis queries.
- `Screenshots/` — dashboard screenshots.
- `Reports/` — business insights PDF.
- `docs/` — project overview and business insights documentation.

## Key Findings
- Overall churn rate: approximately 49.67%.
- Highest regional churn in the displayed results: West, 60.00%.
- Highest age-group churn in the displayed results: ages 21–40, 59.48%.
- Highest-revenue category: Groceries, $134,282.18 (approximately 26.01%).
- CLV segment counts: 208 Low-CLV and 92 High-CLV customers.

## Limitations
Results depend on dataset quality and the correctness of calculations. The displayed loyalty-point values are rounded. Observed relationships do not establish causation. Confirm the source-data currency and permissions before public release.
